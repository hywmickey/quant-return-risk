# 为什么 分红_t = (LJJZ_t − LJJZ_{t−1}) − (DWJZ_t − DWJZ_{t−1})

这是由「单位净值」和「累计净值」两个口径的定义推出来的。

## 定义

- **DWJZ（单位净值）**：每份基金的真实交易价格，除息日当天会被机械地砍掉分红金额（现金发出去了，净值自然下降）。
- **LJJZ（累计净值）**：= 单位净值 + 该基金成立以来**累计发放的每份分红**（简单相加，分红没有再投资）。

即恒等式：

```
LJJZ_t = DWJZ_t + D_t
```

其中 `D_t` 是截至 t 日累计发放的每份分红总额。

## 推导

对相邻两天取差：

```
LJJZ_t - LJJZ_{t-1} = (DWJZ_t - DWJZ_{t-1}) + (D_t - D_{t-1})
```

而累计分红 `D` 只有在除息日才会变化，且增量就是当天那份分红：

```
D_t - D_{t-1} = 分红_t
```

移项即得：

```
分红_t = (LJJZ_t - LJJZ_{t-1}) - (DWJZ_t - DWJZ_{t-1})
```

## 直觉理解

假设某天市场没涨没跌，基金每份分红 0.1 元：

| | DWJZ（单位净值） | LJJZ（累计净值） |
|---|---|---|
| 昨天 | 1.5000 | 1.6000 |
| 今天（除息日） | 1.4000（因分红被砍掉 0.1） | 1.6000（分红加回来了） |
| 变化 | **−0.10** | **0.00** |

- 单位净值跌了 0.1，但那不是真实亏损，是分红除息造成的"虚假下跌"；
- 累计净值没动，因为它把发出去的分红加回来了；
- 两者差值 `0 − (−0.1) = 0.1`，正是当天的每份分红。

有市场波动时也一样：累计净值的变化 = 真实价格波动，单位净值的变化 = 真实价格波动 − 当天分红，差额就是分红。

## 两个注意点

1. **LJJZ 不是全收益曲线**：它只是把历史分红算术累加，没有复利再投资。所以不能用 LJJZ 直接当 level，而要用反推出的分红重建「分红再投资」曲线：

   ```
   level_t = level_{t-1} × (DWJZ_t + 分红_t) / DWJZ_{t-1}
   ```

   （见 `convert_fund.php` 的全收益净值重建逻辑。）

2. **噪声处理与异常兜底**：LJJZ/DWJZ 只公布 4 位小数，两天四舍五入的误差会让公式在非分红日算出 ±0.0001 左右的小值，所以代码里用 `> 0.0005` 的阈值滤掉。另外若基金发生过份额折算/拆分，累计净值口径可能失效，所以脚本还用接口的日增长率 JZZZL 做交叉核对（容差 0.02 个百分点）。
